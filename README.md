# HueyStockstill-Intro
Learning how to use github and an introduction to working with Huey Stockstill

What I learned:
1. The basics for how to set up a github repo and connect it with visual studio code.
2. Learning html, css, and javascript and how they work together.
   - I specifically focused on learning how to use style.css to format groups of items so that it could scale based on window sizes.
   - I also focused on using different things, such as input fields, images, buttons, and returning information sent to and from the js script
3. Connecting a github repo to Vercel to cloud host a website using the code I made.
  - I learned specifically that you can add a vercel.json file that states what website link goes with each html file. This would let us name the html files to be more specific than "index.html" for the homepage.
4. Some of the basics on how asphalt is measured and what some of the variables might be in determining how much extra asphalt is needed. Specifically how much the compaction of laying asphalt affects how much total asphalt is needed. The sources I found for this generally said either a 1/4 inch for every inch laid should be added and others said around 10%. For simplicity I went for showing a range from the exact amount specified to a 10% increase


What could be added on:
1. Switch from html to react
  - While not necessarily needed for a simple calculator website, React would be better to use when there are a lot more moving parts and should be easier to keep updated as it becomes more complex.
2. Add more features, such as:
  - Specifying the specific asphalt being used to get a more exact amount of tons needed
  - Adding more factors to that affect how many tons of asphalt would be needed for a job. For example currently only 10% is added onto the base but more research could be done to get a better approximation.
  - Adding more calculators for different materials, such as concrete, and adding a navigation bar to move between them.
